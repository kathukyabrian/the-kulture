# Admin Features

## Current Capabilities

The admin can currently:

- View active nganyas and their assigned routes.
- See pending-verification counts.
- Approve pending nganyas using the **Verify** action.
- View fleet distribution and crew activity.
- View the live-route dashboard map.
- Sign out.

## Recommended Features

The admin experience should support the fun and cultural focus of The Kulture without introducing revenue management.

### Nganya Management

- Add and edit nganya profiles.
- Hide, suspend, or restore listings.
- Assign nganyas to routes and crews.
- Manage profile details such as sound systems, screens, Wi-Fi, and other features.
- Mark selected nganyas as featured.

### Content and Community

- Approve photos and videos submitted to nganya profiles.
- Moderate comments, reports, and inappropriate content.
- Publish announcements for crews and app users.
- Create events, meetups, and route-takeover notices.

### Discovery and Recognition

- Select a **Nganya of the Week**.
- View trending and popular nganyas.
- Review engagement metrics such as profile views, followers, and reactions.

### Routes and Operations

- Add and update routes.
- Manage route assignments.
- Correct inaccurate or inactive listings.

## Suggested Implementation Priority

1. Nganya profile management.
2. Photo and video approval.
3. Featured nganyas and **Nganya of the Week**.
4. Events and announcements.
5. Community moderation.
6. Route management.
7. Popularity and engagement insights.
